ElectrumSVP 0.2.0-beta.1: Beta release for testing.

This beta release focuses on improved security, verification, transaction control, reliability, and usability. Users are encouraged to test the release and report any problems before the next official release.

For the full release overview, please refer to the official release article .

  • Header security & reliability: Improved header integrity checks, synchronization reliability, and recovery tools, including a new Refresh Headers option.
  • BREAD verification: Faster verification using locally stored proof data, with improved support for unconfirmed transactions and BREAD JSON export.
  • Fee system improvements: Overhauled fee handling and display with greater control, transparency, and additional fee safeguards.
  • UTXO & coin control: Overhauled coin splitting and UTXO management with improved coin selection and fee control.
  • Account & key management: Improved multiple-account support, duplicate-key protection, imported private-key account handling, and custom derivation path display.
  • Address freezing: Improved freeze/unfreeze controls and clearer visual indicators in the Destinations tab.
  • Themes: Added Light, Dark, Pink, and Orange themes through Preferences.
  • USD conversion: Improved fiat conversion with additional providers including Banana Blocks and Whatsonchain.
  • Security fixes: Fixed a nonce issue affecting sweep signing and added various transaction and verification safeguards.
  • Platform compatibility: Fixed several Python 3.10 compatibility issues and Linux segmentation faults affecting recent Ubuntu and Arch-based environments.
  • Bug fixes & UI: Fixed Windows QR scanning and macOS wallet data-path issues, along with numerous smaller interface and reliability improvements.

This is a beta release and additional testing is strongly encouraged. Please report crashes, verification problems, transaction issues, or other unexpected behavior with as much detail as possible.
