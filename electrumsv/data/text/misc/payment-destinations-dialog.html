The Payment Destinations window

This window allows you to generate a list of fresh payment destinations for the selected account. These destinations can be used to create multi-output transactions, for example to split funds across multiple outputs or prepare funds for distribution.

The dialog can also calculate transaction fees, select specific UTXOs to spend, and pass the generated destinations and selected coins to the Pay-to-Many feature.

Depending on the script type used by the account, destinations may be shown as standard Bitcoin addresses or, where the script type does not have an address representation, using the BIP276 format.

How to use

  • # of output destinations: Choose how many fresh destinations to generate. Up to 1,000 destinations can be generated.
  • Mode: Choose how the specified amount is distributed:
    • Equal Split: Divide the specified total amount evenly between all destinations.
    • Random Split: Distribute the specified total amount randomly between the destinations while maintaining the minimum amount per output.
  • Amount: Enter the total amount to distribute among the generated destinations. The amount is interpreted according to the selected split mode.
  • Max: Calculate the maximum amount that can be sent using the available spendable coins, taking the transaction fee into account. If specific coins have been selected using Spend From, the maximum is calculated using those coins instead.
  • Fee Rate: Set the transaction fee rate used when calculating the transaction. Enable Use recommended fee to use the wallet's recommended fee rate.
  • Tx Fee Amount: Displays the calculated transaction fee when a transaction can be constructed using the selected coins and generated outputs.

Coin Control

The Unspent coins/UTXOs section allows you to choose which wallet coins will be used to fund the transaction.

  • Select one or more individual UTXOs to use as funding.
  • You can select an address row to select all of its UTXOs.
  • Right-click selected coins to use Spend From, freeze them, or unfreeze them.
  • Frozen UTXOs cannot be used by Spend From while they remain frozen.
  • Unfreeze All can be used to unfreeze all frozen UTXOs.
  • When specific coins are selected, the dialog uses those coins when calculating the maximum available amount and transaction fee.

Working with destinations

The generated destinations are displayed in the table along with their assigned amounts.

  • Copy: Copy all listed destinations and their amounts to the clipboard.
  • Save: Save the listed destinations and their amounts to a text file.
  • Send to Pay-to-Many: Open the Pay-to-Many send interface with the generated destinations.
  • Preview Pay-to-Many: Open the Pay-to-Many interface so the transaction can be reviewed before it is sent.

Important information

  • Each output must contain at least approximately 300 satoshis. The dialog requires the total amount to be sufficient to provide the minimum amount for every requested output.
  • Transaction fees are calculated separately from the amounts assigned to the destinations. When using Max, the available amount is reduced by the calculated transaction fee.
  • Creating a large number of outputs increases the size of the transaction. More than 100 outputs will produce a warning, and very large transactions may take longer to confirm or may be rejected by some servers.
  • Very small outputs may be uneconomical to spend later because the cost of spending an output can exceed its value.

Possible dangers

The destinations generated by this dialog are not reserved by the wallet. If you copy or save a destination and use it elsewhere, ElectrumSV may still use that destination as part of its normal wallet operation. Therefore, destinations should generally be used for their intended purpose promptly rather than treated as permanently reserved addresses.
